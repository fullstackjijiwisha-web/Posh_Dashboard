# PoSH-Project

POSH Case Management Platform — frontend for Prevention of Sexual Harassment compliance workflows (POSH Act 2013).

## Features

- Role-based demo login (Admin, HR SPOC, Management, IC Member) + MFA
- Dashboard with **Annual Report Submission Format** fields (PoSH Act 2013 workplaces)
- Complaints, Case Workspace, Proceedings, Documents, Evidence, Action Tracker
- Reports & Exports, Audit Log, Admin Settings (Roles / Workflow / Retention)

## Quick start

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173

Demo: pick a quick-access role, then enter any 6-digit MFA code.

## Stack

- React + TypeScript + Vite
- React Router
- Recharts
- Lucide icons
